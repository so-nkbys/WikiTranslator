# Edge Wikipedia 日本語訳併記

Author: whale shark

初版: 1.0.0

**Windows 版 Microsoft Edge 専用**の Tampermonkey ユーザースクリプトです。Edge の右クリックメニュー「日本語に翻訳」で翻訳したページから訳文を読み取り、元の英文の各センテンス直後に `【日本語訳】` を挿入します。

```text
Hello, good morning.[1][2]
【こんにちは、おはようございます。】
What did you do yesterday?
【昨日は何をしていましたか？】
```

日本語訳の前後で改行し、訳文を独立した行に表示します。文末の注釈 `[1][2]` は前の英文に付けたまま、その後に日本語訳を挿入します。「訳文を隠す」では訳文による改行も消えます。英文は変更しません。ご依頼の例では最初の英文が途中で変わっていますが、本スクリプトは原文をそのまま復元します。訳文の表現は Edge の翻訳結果によって変わります。

## 重要：Edge との連携方法

Tampermonkey には Edge の右クリックメニューを実行する API や、内蔵翻訳サービスから結果を直接取得する API はありません。そのため、**メニューの操作は手動**です。ページ上の翻訳済み DOM を読み取る方式であり、Edge が翻訳結果を DOM に反映し、用意したセンテンス要素を保持することが動作条件です。

スクリプトは独自の翻訳 API・非公式 Google エンドポイントを使いません。`@grant none` で、独自のネットワークリクエストも行いません。ただし Edge のページ翻訳自体は Edge の翻訳サービスへ内容を送信します。機密情報には使用しないでください。

## インストール

1. Windows 版 Edge に Tampermonkey をインストールし、有効にします。
2. Tampermonkey の「新規スクリプトを追加」を開きます。
3. 初期コードを削除し、[wiki-translator.user.js](./wiki-translator.user.js) を全部貼り付けて保存します。
4. `https://en.wikipedia.org/wiki/...` または `https://en.m.wikipedia.org/wiki/...` を開きます。

Edge の設定によっては、拡張機能のユーザースクリプト実行許可等を有効にする必要があります。他のブラウザーや Windows 以外では操作パネルを表示しません。

## 操作

右下の操作パネルは「〇 使い方」、①ボタン、②の説明、③ボタンを縦に並べ、空行分の余白を挟んで「原文に戻す」「訳文を隠す」を横に配置しています。「〇 使い方」にホバーすると `"元の言語で表示" メニューは使わないでください`、③にホバーすると `必要に応じ都度押下してください。` を表示します。進捗・エラーは最下段に表示します。

1. **まだ翻訳していない英語の記事**で、右下の「① 原文を保存」を押します。
2. ページの余白を右クリックし、Edge の **「日本語に翻訳」** を選びます。選択した文字列の翻訳ではなく、ページ全体の翻訳を使ってください。メニューの翻訳先が別の言語になっている場合は、Edge の翻訳設定で日本語を選びます。
3. 表示中の文が日本語になったら「③ 英文を差し入れる」を押します。**ページ全体の翻訳完了を待つ必要はありません。**
4. 取得できた文は元の英文に戻し、その直後に `【日本語訳】` を追加します。未翻訳の文は Edge の翻訳対象として残します。
5. スクロールして次の部分が翻訳されたら、再度「③ 英文を差し入れる」を押します。何度押しても処理済みの文に英文や訳文を重複挿入しません。

右下に今回の追加数、累計の取得数、未取得の文数を表示します。新しい訳文がなければ待機メッセージを表示し、引き続き③を押せます。すべての文を取り込んだときだけ③が無効になります。

記事内のタイトル・セクション見出しも①で保存します。Edge が翻訳した後に③を押すと、元の見出しを復元し、その下に少し小さく `【日本語訳】` を表示します。未翻訳の見出しは次回の③まで残し、見出しの取得数も表示します。リンク・見出し ID を保持し、「訳文を隠す」で記事タイトルを含む見出しの訳文も隠せます。目次名は原文のみ復元します。ブラウザーのタブ名は変更しません。

「訳文を隠す／表示」で併記部分のみ切り替えられます。「原文に戻す」は本スクリプトが保存した本文・記事タイトル・見出しの復元です。やり直す場合はページを再読み込みしてください。

**取り込み後に Edge の「元の言語で表示」を使わないでください。** Edge が保持する翻訳前 DOM によって、併記結果が上書きされる可能性があります。Edge の自動翻訳も、最初の原文保存前は無効にしてください。

## 対象と制限

- 本文の段落、末端のリスト項目、定義項目、図の説明をセンテンス単位で処理し、記事タイトル・セクション見出しは見出し全体を一単位で処理します。表、インフォボックス、ナビゲーション、参考文献、コード、数式、明示的な翻訳除外部分は対象外です。子段落を含むリスト項目の親テキストも対象外です。
- センテンスは `Intl.Segmenter` と敬称・略語の補正で区切ります。非対応時は句読点による簡易分割です。複雑な略語等の境界判定は完全ではありません。
- 翻訳準備中から各センテンスを独立した行にし、前後の空白もセンテンス要素内に保持します。隣接要素へ訳文の先頭文字が割り当てられて取得から漏れるリスクを減らすためです。要素の外に文字が出た場合は、不完全な訳文を確定せずエラーを表示します。Edge の出力内容そのものの誤訳・欠損は検出や自動補完できません。
- 原文保存時に対象本文をセンテンスごとのプレーンテキストに一時置換します。**段落内の全センテンスを取り込むまでは、その段落のリンク・強調・注釈等は表示されません。** 取り込み済みの文は先に英文と【日本語訳】で表示し、元の DOM ノードは段落全体の取り込み完了時または「原文に戻す」で復元します。
- 取り込み済みのセンテンスだけに翻訳除外を設定します。未取得のセンテンスと段落全体は、翻訳が続けられる状態のまま残します。
- 日本語文字を含み、原文と異なる結果だけを訳文とみなします。固有名詞等が英語のままの場合は未取得として残るため、全件完了にならない場合があります。そのまま読めますが、段落内の元の装飾は全件取得または原文復元まで戻りません。
- 文の翻訳途中で取り込むと部分的な訳文を確定する可能性があります。ページ全体を待つ必要はありませんが、取り込む範囲の文が翻訳し終わってから③を押してください。
- 新しい日本語訳がない場合は未取得数を明示して待機します。翻訳用 DOM が失われた場合はエラーを表示し、取り込みを停止します。Edge が DOM に訳文を公開しない環境では動作しません。
- 表・インフォボックスなど、本文・記事タイトル・見出し以外の対象外部分は Edge のページ翻訳のまま残る場合があります。「原文に戻す」でもこれらは復元しません。ページ全体を元に戻すには再読み込みしてください。
- 翻訳中の Wikipedia の画面更新や記事移動には対応しません。再読み込みすると保存した原文・訳文は消えます。

## 開発用テスト

```powershell
npm install
npm run check
npm test
```

テストは翻訳後の DOM を模擬し、外部サービスには通信しません。センテンスの分割、原文の復元、リンク保持、順不同の逐次取り込み、重複防止、待機、Windows Edge 限定、取得失敗を検証します。**実際の Edge 内蔵翻訳との互換性は、Windows Edge で上記の操作を実行して別途確認する必要があります。**
